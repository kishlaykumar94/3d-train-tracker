Data notes. Live data comes from NTES (enquiry.indianrail.gov.in) through server.py: actual/projected times per stop (* = projection), every non-stopping station, the last confirmed location and the coach list. Between NTES updates a train's position is extrapolated at ~85 km/h to its next stop, so it is an estimate, not GPS. Top speed per train is derived from its own timetable. Both trains are assumed to run the same direction along their shared route.
